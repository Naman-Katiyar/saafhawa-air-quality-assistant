# SaafHawa — Urban Air Quality Assistant

Built for **PromptWars Virtual, Challenge 06 — Urban Air Quality Assistant**: help families beat severe winter smog with personalised low-emission routines and indoor air hacks.

## What it does

- **Live air quality for any city** — current US AQI, PM2.5 and PM10, plus a colour-coded 24-hour AQI chart with the day's cleanest stretch highlighted. Data comes from the free Open-Meteo Air Quality API (Copernicus Atmosphere Monitoring Service); city search uses the Open-Meteo Geocoding API. No API key or sign-up needed.
- **A personalised daily plan for your family** — tick who is at home (young children, elders, asthma/allergy, pregnancy, outdoor work/commute, morning fitness) and the plan is rebuilt from the live AQI: walk timing, school-run precautions, mask advice, ventilation windows and workout calls for each member.
- **Best outdoor window** — the app scans the next 40 hours and finds the cleanest 3-hour stretch, then builds the day's routine around it.
- **Indoor air hacks that actually move the needle** — including a purifier sizing calculator (room dimensions → required CADR at 5 air changes/hour for smog season), ventilation timing, sealing, wet-mopping, and indoor smoke sources.
- **Ask SaafHawa** — an advisor that answers questions (masks, exercise, school, windows, purifiers, commute) from the live AQI and your family profile. Optionally, paste your own Gemini API key in Settings and answers are generated by Gemini (`gemini-2.0-flash`) with the live data as context; the key is stored only in your browser.
- **Low-emission routine swaps** — small, keepable changes (shifted school runs, pooled commutes, batched errands in the clean window) that cut both emissions and exposure.

## Run it

It is a static site — no build step, no dependencies.

- Open `index.html` in a browser, or
- serve the folder: `python3 -m http.server 8000` and visit `http://localhost:8000`

An internet connection is needed for the live air-quality data.

## Files

- `index.html` — page structure and content
- `styles.css` — styling (flat, professional, mobile-friendly)
- `app.js` — data fetching, AQI logic, plan generator, purifier calculator and the advisor

## Notes

- AQI shown is the **US AQI** scale. Health messages follow standard public-health guidance for each AQI band.
- The app gives general guidance, not medical advice.
- Family profile and the optional Gemini key never leave the browser (profile is kept in memory; the key in `localStorage`).
